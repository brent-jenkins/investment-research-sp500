# Investment Research Dashboard

A local/self-hosted Streamlit app for daily market analysis, regime detection, and confluence-based trade signals.

## Running locally

```powershell
pip install -r requirements.txt
python -m streamlit run main.py
```

First-run sequence: **Refresh Data** → **Run Analysis** → **Generate Signals**.

Add your FRED API key to `config.yaml` under `macro.fred_api_key` (free at https://fred.stlouisfed.org/docs/api/api_key.html). Without it, yield-curve scoring returns 0; VIX scoring still works.

## After cloning

Run this once to install the git hooks:

```bash
bash setup-hooks.sh
```

This installs a pre-push hook that automatically deploys to [research.example.com](https://research.example.com) whenever you push to `main`. To push without deploying (e.g. draft commits): `DEPLOYING=1 git push origin main`.

## Server deployment

### Infrastructure

| Item | Value |
|------|-------|
| Provider | Cloud VPS |
| Plan | 2 vCPU / 4 GB |
| OS | Ubuntu 22.04 LTS |
| User | root |
| App directory | `/root/investment-research` |

### First-time setup

```bash
# 1. Clone the repo
git clone https://github.com/YOUR/investment-research.git /root/investment-research
cd /root/investment-research

# 2. Copy and edit server-specific config files (not in git — see .gitignore)
cp .streamlit/config.toml.example .streamlit/config.toml   # edit port/domain
# Create config.yaml from scratch or copy from local machine, add FRED key
# Create Caddyfile from Caddyfile.example, add domain + bcrypt password hash

# 3. Run setup script
bash setup.sh your.domain.com
```

`setup.sh` performs these steps:

1. Installs system packages + Python 3.11 via `apt`
2. Compiles the TA-Lib C library from source
3. Installs Caddy via the official apt repo
4. Installs all Python packages system-wide: `python3.11 -m pip install -r requirements.txt`
5. Writes `.streamlit/config.toml` for headless/reverse-proxy mode
6. Copies `Caddyfile` to `/etc/caddy/Caddyfile`
7. Installs and starts the `investment-research` systemd service

### HTTPS / reverse proxy

Caddy handles TLS (automatic Let's Encrypt) and basic-auth in front of Streamlit. After setup, set the dashboard password:

```bash
caddy hash-password          # enter your password; copy the hash output
nano /etc/caddy/Caddyfile    # replace REPLACE_WITH_HASH with the hash
systemctl reload caddy
```

### Systemd service

The app runs as a systemd service and restarts automatically on crash or reboot.

```bash
systemctl status investment-research
journalctl -u investment-research -f   # live logs
systemctl restart investment-research
```

The APScheduler job fires at **21:30 UTC every weekday** (after NYSE close) to pull incremental price data, run analysis, and recompute cross-asset correlations. Exchanges are checked individually via `pandas_market_calendars`; assets on closed exchanges are skipped.

### Deploying updates

```bash
# From Windows Git Bash:
bash deploy.sh
# or with an explicit server IP:
VM_IP=1.2.3.4 bash deploy.sh
```

`deploy.sh` pushes to GitHub, pulls on the server, reinstalls any new packages, and restarts the service.

### Files not tracked in git

These files contain secrets or are server-specific — manage them directly on the server:

- `config.yaml` — FRED API key, watchlist, scheduler timing
- `Caddyfile` — domain name, bcrypt password hash
- `.streamlit/config.toml` — generated by `setup.sh` with your domain
- `database/*.db` — SQLite database (price data, signals, trades)
